Wavely API Developer Reference

API Reference documentation for integrating Wavely audio search & decryption capabilities directly into your custom apps.

Authentication

All incoming API requests to the Wavely catalog proxy system must include a valid API key passed as an HTTP header token. You can generate and revoke API keys inside your developer dashboard panel.

Header Format: X-API-Key: wv_<your_key_hash>

Errors & Logging

We log every incoming API response along with timestamps, calling IP address, endpoint paths, and success outcomes. These logs are accessible via the dashboard for troubleshooting.

HTTP Status Codes

Code Description
200 OK Request succeeded. Returns requested data payload.
401 Unauthorized API key is missing or revoked. Check the X-API-Key header value.
403 Forbidden Your calling IP address has been banned by the administrator console.
404 Not Found The requested resource, asset, or decryption UUID could not be located.

Search Catalog

GET /api/search

Queries the external Splice library preview system in real-time, matching queries, root keys, and instrument categories.

Query Parameters

Parameter Type Required Description
q string Yes The query term (e.g. synth loop).
key string No The key to search for (e.g. Cmin, G#maj).
instrument string No Filter by category (e.g. synth, drums, bass).
type string No Filter by type: oneshot or loop. 
import requests

url = "http://127.0.0.1:5000/api/search"
headers = {"X-API-Key": "wv_YOUR_API_KEY"}
params = {"q": "synth loop", "instrument": "synth"}

response = requests.get(url, headers=headers, params=params)
print(response.json())
const fetch = require('node-fetch');

fetch('http://127.0.0.1:5000/api/search?q=synth+loop&instrument=synth', {
  headers: { 'X-API-Key': 'wv_YOUR_API_KEY' }
})
.then(res => res.json())
.then(data => console.log(data));
curl -H "X-API-Key: wv_YOUR_API_KEY" \
  "http://127.0.0.1:5000/api/search?q=synth+loop&instrument=synth"

Decrypted Preview Audio

GET /api/decrypted-audio/<uuid>

Retrieves the decrypted preview audio binary matching the requested sample UUID. Transcodes dynamically on-demand.

Path Variables

Variable Type Required Description
uuid string Yes The UUID of the sample to pull and decrypt.

Query Parameters

Parameter Type Required Description
format string No The output file format. Allowed values: mp3, wav. WAV format provides raw PCM transcoding. 
import requests

uuid = "085bd422-bf47-4144-9c9d-a74ee502c368"
# Request as WAV format
url = f"http://127.0.0.1:5000/api/decrypted-audio/{uuid}?format=wav"
headers = {"X-API-Key": "wv_YOUR_API_KEY"}

response = requests.get(url, headers=headers)
with open("decrypted_sample.wav", "wb") as f:
    f.write(response.content)
print("Saved decrypted WAV sample successfully!")
const fetch = require('node-fetch');
const fs = require('fs');

const uuid = '085bd422-bf47-4144-9c9d-a74ee502c368';
fetch(`http://127.0.0.1:5000/api/decrypted-audio/${uuid}?format=mp3`, {
  headers: { 'X-API-Key': 'wv_YOUR_API_KEY' }
})
.then(res => res.buffer())
.then(buffer => {
  fs.writeFileSync('decrypted_sample.mp3', buffer);
  console.log('Saved decrypted MP3 sample!');
});
curl -H "X-API-Key: wv_YOUR_API_KEY" \
  "http://127.0.0.1:5000/api/decrypted-audio/085bd422-bf47-4144-9c9d-a74ee502c368?format=wav" \
  -o sample.wav

Guide: Scrape Search Counts

Learn how to query the search API, parse the results, and inspect the total number of matched samples from the Splice catalog catalogued for query pagination.

Example: Querying and Scraping Search Counts (Python)
import requests

url = "http://127.0.0.1:5000/api/search"
headers = {"X-API-Key": "wv_YOUR_API_KEY"}
params = {
    "q": "Synth lead",
    "category": "loop"
}

# 1. Fetch Search Results
response = requests.get(url, headers=headers, params=params)
data = response.json()

# 2. Extract Count & Results
total_found = data.get("count", 0)
samples = data.get("results", [])

print(f"Total samples found: {total_found}")
for i, sample in enumerate(samples[:5]):
    print(f"[{i+1}] {sample['name']} | BPM: {sample['bpm']} | Key: {sample['key']}")

Guide: Download & Stream Audio

This guide covers how to stream decrypted audio previews dynamically inside browser elements or download files directly onto your disk storage.

1. Web Streaming (HTML5 Audio Player)

To stream real-time decrypted audio directly inside a client web application, set the source URL of an HTML5 <audio> element to the decryption API endpoint, passing your key in the query string:

HTML Embed Template
<audio controls>
  <source src="http://127.0.0.1:5000/api/decrypted-audio/085bd422-bf47-4144-9c9d-a74ee502c368?api_key=wv_YOUR_API_KEY" type="audio/mpeg">
  Your browser does not support the audio tag.
</audio>

2. Dynamic Chunk Streaming (Node.js)

For script integrations, stream the file in chunks rather than buffering everything in memory to ensure low resource usage:

Dynamic Streaming in Node.js
const http = require('http');
const fs = require('fs');

const url = 'http://127.0.0.1:5000/api/decrypted-audio/085bd422-bf47-4144-9c9d-a74ee502c368?format=wav';
const options = {
  headers: { 'X-API-Key': 'wv_YOUR_API_KEY' }
};

http.get(url, options, (res) => {
  if (res.statusCode !== 200) {
    console.error(`Request Failed. Status: ${res.statusCode}`);
    return;
  }

  const fileStream = fs.createWriteStream('sample.wav');
  res.pipe(fileStream);

  fileStream.on('finish', () => {
    fileStream.close();
    console.log('Download complete!');
  });
});
