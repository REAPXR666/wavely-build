API Developer & Creator Reference

Complete guide to Wavely's catalog, decryption, battles, servers, and direct communication layers.

Authentication

Wavely V2 employs two different methods of authentication depending on the endpoint type:

  • Developer Catalog APIs: Authenticated using the X-API-Key HTTP Header. Obtain your key from your user dashboard.
  • Community & Messaging APIs: Authenticated using your active browser session cookie. If scripting against these endpoints, you can log in via the authentication action endpoint to retrieve your session cookies, or supply your active session cookie in the Cookie header.
API Key Header Format: X-API-Key: wv_<your_key_here>
Session Cookie Header Format: Cookie: session=<your_session_value>

Errors & Response Codes

Standard JSON payloads are returned for error states with a descriptive error string. The following HTTP status codes are used:

Code Meaning Description
200 OK Request completed successfully.
400 Bad Request Missing parameters or validation limits exceeded (e.g. password too short).
401 Unauthorized Invalid or missing API key, or not logged in.
403 Forbidden Action not permitted (e.g. post in a locked channel, or IP has been banned).
404 Not Found Requested resource (server, channel, battle) does not exist.
429 Too Many Requests Rate limit exceeded on authentication endpoints.

Catalog & Audio APIs

Search Catalog

GET/api/search

Queries the global music sample catalog with various metadata filters.

Parameter Type Required Description
q string Yes Text query (e.g., synth loop).
category string No Filter by instrument family (e.g., drums, vocals).
key string No Filter by musical key (e.g., Amin, C#maj).
type string No Filter by sample type: one-shot or loop. 
import requests
url = "http://127.0.0.1:5000/api/search"
headers = {"X-API-Key": "wv_YOUR_API_KEY"}
params = {
    "q": "drum loop",
    "key": "Cmin",
    "type": "loop"
}
response = requests.get(url, headers=headers, params=params)
print(response.json())
const url = new URL("http://127.0.0.1:5000/api/search");
url.searchParams.append("q", "drum loop");
url.searchParams.append("key", "Cmin");

fetch(url, {
  headers: { "X-API-Key": "wv_YOUR_API_KEY" }
})
.then(res => res.json())
.then(data => console.log(data));
curl -H "X-API-Key: wv_YOUR_API_KEY" \
  "http://127.0.0.1:5000/api/search?q=drum+loop&key=Cmin&type=loop"

Decrypt Audio File

GET/api/decrypted-audio/<uuid>

Retrieves the fully decrypted raw audio binary stream. Supports switching output containers dynamically.

Parameter Type Required Description
format string No Container format: wav (default) or mp3. 
import requests
uuid = "sample-uuid-here"
url = f"http://127.0.0.1:5000/api/decrypted-audio/{uuid}"
headers = {"X-API-Key": "wv_YOUR_API_KEY"}
params = {"format": "mp3"}

response = requests.get(url, headers=headers, params=params)
with open("decrypted_sample.mp3", "wb") as f:
    f.write(response.content)
print("File downloaded successfully.")
const uuid = "sample-uuid-here";
fetch(`http://127.0.0.1:5000/api/decrypted-audio/${uuid}?format=wav`, {
  headers: { "X-API-Key": "wv_YOUR_API_KEY" }
})
.then(res => res.blob())
.then(blob => {
  const audioUrl = URL.createObjectURL(blob);
  const audio = new Audio(audioUrl);
  audio.play();
});
curl -H "X-API-Key: wv_YOUR_API_KEY" \
  -o sample.wav "http://127.0.0.1:5000/api/decrypted-audio/sample-uuid-here?format=wav"

Submit Track Entry

POST/api/battles/submit

Submits a finished track to an active beat battle thread.

Field Type Required Description
battle_id string Yes Target battle identifier.
sample_url string Yes Link to the submitted audio track.
comments string No Description of plugins, DAWs, or techniques used. 
import requests
url = "http://127.0.0.1:5000/api/battles/submit"
headers = {
    "Cookie": "session=YOUR_SESSION_COOKIE",
    "Content-Type": "application/json"
}
payload = {
    "battle_id": "btl_12345",
    "sample_url": "https://storage.googleapis.com/user-beats/beat.mp3",
    "comments": "Made with FL Studio and the decrypt audio API!"
}

response = requests.post(url, headers=headers, json=payload)
print(response.json())
fetch("/api/battles/submit", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    battle_id: "btl_12345",
    sample_url: "https://storage.googleapis.com/user-beats/beat.mp3",
    comments: "Made with Logic Pro X"
  })
})
.then(res => res.json())
.then(data => console.log(data));
curl -X POST --cookie "session=YOUR_SESSION_COOKIE" \
  -H "Content-Type: application/json" \
  -d '{"battle_id":"btl_12345","sample_url":"https://storage.googleapis.com/user-beats/beat.mp3"}' \
  http://127.0.0.1:5000/api/battles/submit

Creates a new guild server. Send values as Form Data parameters to support optional file upload banners.

files = {"icon": open("icon.png", "rb")}
data = {"name": "Producers Guild"}

response = requests.post(url, headers=headers, data=data, files=files)
print(response.json())
const formData = new FormData();

Send Chat Message

POST/api/servers/messages/send

Sends a text message and/or upload attachment to a channel. Use Form Data format.

Parameter Type Required Description
server_id string Yes Target server.
channel_id string Yes Target channel.
content string No Message body text. Optional if uploading a file attachment.
attachment binary file No Optional file upload (e.g. .wav sample or image). 
import requests
url = "http://127.0.0.1:5000/api/servers/messages/send"
headers = {"Cookie": "session=YOUR_SESSION_COOKIE"}
data = {
    "server_id": "srv_123",
    "channel_id": "chan_456",
    "content": "Check out this kick sample!"
}
files = {"attachment": open("kick.wav", "rb")}

response = requests.post(url, headers=headers, data=data, files=files)
print(response.json())
const formData = new FormData();
formData.append("server_id", "srv_123");
formData.append("channel_id", "chan_456");
formData.append("content", "Hey guys!");

fetch("/api/servers/messages/send", {
  method: "POST",
  body: formData
})
.then(res => res.json())
.then(data => console.log(data));
curl -X POST --cookie "session=YOUR_SESSION_COOKIE" \
  -F "server_id=srv_123" \
  -F "channel_id=chan_456" \
  -F "content=Checkout this link wavely.lol/join/invite-code" \
  http://127.0.0.1:5000/api/servers/messages/send
